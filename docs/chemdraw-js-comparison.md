# 与 ChemDraw JS 的功能对照

核对日期：2026-11-05。比较对象是可嵌入的 ChemDraw JS 网页编辑器及其可选 Web Service，不把 ChemDraw 桌面版全部菜单算作网页版本功能。

当前结论：普通二维编辑和若干计算工作流正在接近，但尚未通过同任务、同输入、同输出的等价验收；没有证据支持整体超越。样本解析通过、功能名称相同或加入 AI，都不足以证明引擎等价。

| 范围 | 官方 ChemDraw JS 已列能力 | 当前项目及差距 |
| --- | --- | --- |
| 基础绘图 | 原子、链、环、键、箭头、文字、电荷及价态检查 | 已有普通绘图及导入图元编辑；完整绘图工具、实时化学检查和交互细节仍需完善 |
| 查询 | 通用原子、元素列表、键类型和拓扑查询 | 已有元素／NOT、通用与任意原子、查询键，以及取代数、环键数、不饱和、反应条件和环／链拓扑的解析编辑保存；完整 Markush 求值、SMARTS 与数据库匹配仍未实现 |
| 模板 | 氨基酸、双环、环烷烃等 | 内置模板较少；能导入模板内部图不等于具备相同模板操作体验 |
| 排版 | 结构和反应清理 | 普通完整分子可用 RDKit 二维清理；尚无完整反应排版流程 |
| 标签 | 展开与收起化学标签 | 已有原子级展开与选区收起，以及保留残基、候选和引用的可编辑群组展开视图；支持 JSON/CDXML 视图状态保存。原子提升限内外同阶普通键，整体注释等保持其群组身份 |
| 格式接口 | CDXML、MOL、RXN、SMILES、InChI、InChIKey 等 | 已有 CDX/CDXML/MOL/MRV/JSON、单条分子 SMILES 和单步 RXN V2000/V3000；RXN 高级语义、InChI 和 InChIKey 仍有缺口 |
| 文件保真 | 与 ChemDraw 文件及桌面交换 | 有来源保留保存及严格损失诊断；复杂 CDX 从零重建、跨格式覆盖和商业软件往返仍有限制 |
| 桌面／Office 交换 | 化学剪贴板、Office 往返，部分流程需浏览器扩展 | 尚无相同的原生化学剪贴板／Office 集成 |
| 化学计算 | 官方 API／可选服务支持性质等功能 | 已有本地 RDKit 普通分子分析、常见立体标签；不覆盖全部高级化学语义 |
| 自动化与定制 | 官方公开嵌入与应用集成 API | 当前已有 SDK、命令插件、本地模型及自然语言操作；这是现成的产品集成，不能据此断言对方无法实现同类扩展 |

功能清单依据 [官方 ChemDraw JS 说明](https://revvitysignals.com/sites/default/files/2024-12/rs-flyer-ChemDraw_JavaScript_Sketcher.pdf)。部署范围以较新的 [官方示例仓库](https://github.com/Revvity/ChemDraw-JS-Public-Examples) 为准：npm 客户端、XML 许可证、可选 Docker Web Service 和配套文档。官方明确区分网页 sketcher 与通用化学任务服务。

## 接近等价的验收方式

后续对每项能力使用相同输入，核对化学身份、可编辑行为、保存再打开、目标格式、撤销和操作步骤。已补充标签收起、群组展开、基础 RXN 及七类原生查询字段，见 [查询验证](validation/query-constraints/README.md)。下一批缺口包括反应清理、完整查询匹配与 Markush 求值、复杂立体计算、RXN 高级约束、InChI 交换、原生剪贴板及跨软件验证。

“超越”适合按具体指标评价，例如某项本地自动化流程的操作步骤、耗时、数据留在本机的部署方式、业务扩展成本。当前没有与商用 ChemDraw JS 的完整并行基准，不能给出可靠的总体功能百分比。现有 685 份文件回归也只证明报告列出的文件与编辑路径。
