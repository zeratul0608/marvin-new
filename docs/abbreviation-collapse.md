# 将选区收起为可编辑缩写

选中一个连通化学片段，在右侧“结构与属性”展开“收起为缩写”，输入显示名称并点击“将选中片段收起”。名称只控制显示，内部保留实际原子、键和明确的连接端口；名称不会被当作 SMILES 或化学结构重新猜测。

## 已实现

- 支持整个连通分子，或通过单键连接外部结构的连通选区。内部可包含完整芳香环、双键、四面体中心、同位素、电荷和已有嵌套缩写。
- 每条跨选区边界的键保留原外部键 ID，在内部建立独立虚拟端口与端口键。选中原子和内部键保留原 ID；再次展开时，未与当前主图冲突的 ID 直接恢复，冲突才使用确定性哈希。
- 保留内部四面体和双键排序、楔线及已建模的键描绘，重写跨边界的键引用。收起时复核内部及外部立体对应，清除需要重新计算的 CIP 缓存。完整内部 And／Or 增强立体组可以保留；展开时按冲突情况保留或重分配组号。
- 同步页面／分组、反应分子参与者及聚合物成员。聚合物 crossing bond 的组内端点改为新包装节点，展开后根据对应端口恢复锚点。
- 收起后的内部图可通过已有内部编辑器修改，也能添加并绑定新的外部端口。整个收起对应一步撤销，支持重做和原生 JSON 保存恢复。

包装节点定位在各边界内部锚点的平均位置；没有外部边界时使用选中原子的平均位置。内部保留原坐标；展开使用已有端口拟合进行旋转和平移，不镜像。

```ts
const snapshot = editor.getSnapshot();
const result = editor.applyEdits({
  expectedRevision: snapshot.revision,
  operations: [{
    type: 'collapse-substructure',
    atomIds: snapshot.selection.atomIds,
    label: 'OMe',
    ref: '$collapsed',
  }],
});
const wrapperId = result.created.atoms.$collapsed;
```

## 编辑保护

以下情况会明确拒绝整次收起，不提交部分修改：

- 空选区、重复／不存在的原子、不连通选区、空名称或超过 500 字符的名称。
- 双键或芳香键跨边界；同一外部原子连到选区两个端点，收起会产生重复键；内部边界锚点本身是模板连接点。
- 选区包含轴立体节点或其轴参与原子；多中心连接、增强立体组横跨选区边界。
- 选区横跨页面、分组、聚合物成员或反应参与者范围；独立对象引用只覆盖部分选区；反应单原子映射引用选中原子。
- 独立对象需要继续引用被移入内部的单个原子或键，而没有明确的包装节点语义；内部键与外部键的 crossing 描绘互相引用。

可把完整双键或芳香环选入内部来满足单键边界；不要求所有内部键都是单键。被拒绝的内容仍保留在原文档，可继续编辑。

## CDXML 来源保存

针对原生 CDXML，来源保存将可信来源中的原始 `n`／`b` 元素真正搬入新建的内部 `fragment`，保留原生字体、标签样式及未被修改的保留属性。新建包装标签、内部端口和端口键，并更新外部连接、聚合物及反应引用。

内部子文档获得经过重新解析和稳定 ID 绑定的来源基线。随后修改内部元素、同位素或增加原子，再次来源保存会继续基于原生内部文件写入；嵌入父文档时只重编号发生父子冲突的原生 ID。模型 ID 与 CDXML 原生对象 ID 是不同的身份层，不通过用户 JSON 的路径或原生 ID 直接授权搬移。

已验证直接收起、完整分子收起、两次嵌套收起，以及“原缩写 → 展开 → 改名重新收起”的来源保存。原包装节点仍在其他层级时只搬移；包装节点已被真实展开时，先提升原始来源，再执行新收起。JSON 恢复后仍可继续此流程。

来源保存还会拒绝以下无法可靠映射的情况：选中成员来自不同原生分子片段；来源边界与当前端口不一致；相关原生 ID 或目标局部 ID 重复、去向不明确；内部原生引用指向范围外对象；私有或未知引用；边界键附有归属不明确的原生子对象。内部端口先改绑再展开的来源保护仍然有效。

本轮原生搬移只覆盖 CDXML。CDX 来源的同类搬移未实现；可保留原生 JSON，或按格式报告明确选择重建。新收起的结构可重建为带内部片段的 CDXML，重建导出的样式保留范围与来源保存不同。以上能力不等于全部 ChemDraw 对象均可无损重写。
