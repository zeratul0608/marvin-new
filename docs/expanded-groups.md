# 保留化学身份的群组展开与编辑

带残基注释、整体电荷、图形引用或多个候选的片段，可以在“结构与属性”点击“展开结构并编辑”。主画布下方显示真实内部原子和键，所有候选分别显示；点击任一内部原子或键，会打开同一套化学编辑器并定位到该对象。保存作为主文档的一步修改，可以撤销重做。

“展开全部内部层级”同时显示嵌套片段。每个点击目标保存完整的片段／分支路径，内部局部 ID 即使重复，也不会把修改错误应用到主图或其他候选。内部仍支持原子／键属性、绘制、移动、删除、立体约束、端口映射和进一步的内部编辑。

## 两种展开的用途

- **群组展开视图**保留原包装节点、真实内部图、全部候选及其身份。残基编号和 Peptide 类型仍属于原残基；整体注释不被猜测分配给某个内部原子。原生 LonePair 等图形的引用也继续指向原对象。多分支表示“备选”，不会作为多个同时存在的普通分子计算。
- **原子级提升**删除缩写包装，把真实内部图接入主图，适用于归属明确的单一结构。边界支持内外同阶的单／双／三键，并核对立体对应。无法可靠改写的整体注释、备选和引用仍不允许平铺。

这两种方式可以按编辑需要选择。群组展开完整呈现并编辑内部图，不等于将所有复杂化学语义转换成一个确定的平面分子。

## 外部连接与原文件问题

展开卡片用 B 编号标记外部键，用 P 编号标记内部端口；同一映射在卡片中列出。外部连接点保留菱形，未绑定端口单独说明。

原文件若含不同的内外键型，例如外部芳香键、内部单键，两侧信息均保留。在属性面板可以查看差异，分别选择外部键或内部键修改。编辑器不会为了让展开通过而自动替换键型或改造来源结构。

## 保存与接口

原生 JSON 保存完整层级图及展开状态。CDXML 来源保存保留原包装节点与全部原生化学属性，并以标准隐藏 `objecttag` 记录视图状态：

```xml
<objecttag Name="MoleculeWorkbench.ExpandedView" TagType="String"
           Value="1" Persistent="yes" Visible="no"/>
```

这个标记只描述本编辑器的显示方式，不承担残基、电荷或候选等化学语义；这些内容仍在原生节点和片段中。其他软件可以忽略该视图标记。未改化学的展开／收起只增删标记，不重写内部图、字体、坐标、立体缓存或对象引用。内部修改后仍使用来源保存机制，并在重新解析后比较完整模型。

```ts
editor.applyEdits({operations:[{
  type:'set-substructure-display',
  atomId:wrapperId,
  expanded:true,
  recursive:true,
}]});
```

将 `expanded` 设为 `false` 可收起视图。本轮持久化覆盖 JSON 和 CDXML；不宣称 CDX 已有相同视图标记写入能力。普通原子级展开接口保持原有含义。

## 验证

原来受保护的 250 个目标按原生对象 ID 固定在[目标清单](validation/expanded-groups/targets.json)。验证逐项检查真实内部图、全部分支编辑、来源保存回读、JSON 恢复及撤销重做，不以绕过保护检查计为成功。

自动测试覆盖视图状态、原生内容不变、全部候选、实际点击定位、嵌套路径、编辑与撤销、键型冲突及同阶多重键。完整结果与可复现命令见[验证目录](validation/expanded-groups/README.md)。
