# 文档编辑手动样例

5 份 CDXML 为本项目独立构造，不含商业安装包样本。可在 `/test-files/index.html` 的 **08-document-editing** 下载，或下载总 ZIP。

- `reaction-original.cdxml`：两个分子片段、箭头、条件文字、反应步骤及原子对应关系。选择工具可拖动箭头；属性面板的文档对象列表可选文字，反应步骤内可调整角色。
- `reaction-edited.cdxml`：同位素 13 标记、80 °C 条件、箭头位移后的来源保存结果。
- `nested-original.cdxml`：O-link 内部有氧原子及两个真实边界连接点。选择缩写节点并打开内部结构，修改氧为硫后保存，再测试撤销重做。
- `nested-edited.cdxml`：内部氧改硫、缩写改为 S-link 后的来源保存结果。
- `multipage.cdxml`：属性面板选择第 1／2 页，检查显示内容切换，而完整文档仍保留两页。

导出时选择“源格式保留保存”，重新导入下载文件，核对修改。对于数据模型、已测路径及仍有限制的专用绘图对象，参见 [引擎升级说明](../../engine-upgrade.md)。
