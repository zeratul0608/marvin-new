# RXN 实测报告

验证日期：2026-11-05。使用项目统一构建后的 SDK、开发服务器、本机 Chrome 与独立 Python RDKit 2025.03.6；未启动或测试 AI 模型。

| 验证层 | 实测结果 | 核对内容 |
| --- | --- | --- |
| RXN 专项测试 | 36 项通过 | 两版读写、角色与映射、同位素、楔键方向、六种反应键条件、编辑与 JSON 恢复、截断及不支持语义的拒绝 |
| SDK 文件准备 | 12 / 12 成功 | 两版原始／同位素修改／反应键中心／手性样例，共 8 个；原生生成及应用重建的双向样例，共 4 个 |
| 原生独立解析 | 12 / 12 成功 | 分别比较反应物、产物及试剂的数量与带映射的异构 SMILES；保留电荷、同位素与手性；两版 RXCTR 12 / 8 均通过 |
| 浏览器文件导入 | 2 / 2 成功 | 通过文件输入导入两版 RXN，点击选择映射编号 1 的反应物原子，通过可见属性框把碳-13 改成碳-14，并使用撤销／重做按钮 |
| 浏览器实际下载 | 4 / 4 成功 | 每版导入分别导出 V2000 与 V3000；不允许有损导出，下载后重新解析并核对三个角色、映射 1 / 2 及配对、两侧同位素 14 / 13 和反应键条件 |

手性样例在两版文件中均由原生 RDKit 判为 `S`。浏览器验证期间未记录页面运行错误。下载验证使用真实下载文件，未用导出预览文本代替。

机器结果：[SDK 自检](adapter-results.json)、[原生独立验证](independent-results.json)、[浏览器验证](browser-results.json)。生成与复现命令见 [README](README.md)。

本次通过范围是单步、普通二维分子的 RXN 交换。显式 VAL、INVRET／EXACHG、查询／S-group、增强立体等不支持的语义仍明确拒绝；原生夹具使用普通隐式氢表示，没有剥除导入文件中的限制字段。当前结果不代表完整 ChemDraw 兼容认证，也不表示 RXN 可无损保存完整 ChemDraw 文档。
