测试日期：2026-11-06。对象为当前工作区的 Molecule Workbench（`HEAD 2112c16` 加未提交的改动），运行于 `http://127.0.0.1:5173/`。

## 结论

日常结构录入、复杂片段内部修改、代表性格式导出重开，以及真实 AI 辅助编辑均能完成；保护性拒绝能避免若干不可靠的化学转换。但当前还存在会影响工程师放心工作的草稿可靠性、反应信息呈现、焦点和结果阅读问题。

优先修复 **多标签页静默覆盖本地草稿（P1）**。本轮没有发现导出文件被静默破坏的证据；此结论只适用于已测试的样例。

共完成 **68 项任务/操作检查**（核心 56 项、日常工作台补测 5 项、大文档操作 7 项），记录 **21 项问题：P1 × 1、P2 × 18、P3 × 2**，包括能力缺口。原始状态归一化后为 56 项通过、8 项完成但有摩擦、3 项能力受限、1 项失败；通过也可能伴随体验问题。[机器汇总](results/summary.json)。

## 使用者与任务

按化工研发工程师的工作顺序走查：收到同事的结构或反应文件 → 核对反应物、产物、同位素与立体信息 → 修改结构或条件 → 计算普通分子的性质 → 把图及结构文件交给同事 → 刷新或重新打开后继续工作。

重点检查“找不找得到入口、是否理解当前对象、操作能否撤回、保存范围是否明确、结果是否方便核对”。这是专家场景走查，未招募真人用户，不提供主观满意度分数或与 ChemDraw 的百分比匹配度。

## 方法与环境

- Chrome headless，通过真实页面控件、鼠标、键盘、文件选择器和浏览器下载执行工作流；所有结构和选区变更均走 UI。
- SDK `getDocument/getSnapshot` 仅用于只读核验；未调用写入 API 帮助完成任务。Undo 定位时额外只读记录了历史摘要。
- 桌面视口包括 1280、1440、1600 像素，窄屏视口 390 像素；中英文覆盖基础切换、AI 布局及英文计算流程，并非全部文案逐条国际化审计。
- AI 使用本机 Docker 中的 **qwen3.6-27b**，经真实工具调用连接本地 RDKit；没有用模拟响应替代。完成 11 次自然语言提交、18 次模型响应，另有停止中的请求。
- 使用仓库自有/公开测试样例和合成结构；未执行商业安装包或使用商业安装包内的语料。本轮没有修改生产代码及模型配置。
- 页面异常监听未捕获 JavaScript 异常。任务耗时是自动化执行及模型等待时间，不能作为真人学习时间或性能承诺。

### P1：多标签页静默覆盖本地草稿

编号 `B-F04`，核心任务 `B13`，两轮独立运行均复现。

1. A 页手绘乙醇并保存；同一浏览器另开 B 页，恢复同一份草稿。
2. B 页把氧电荷改为 −1，页面显示“已保存到本机”。
3. A 页只修改文档名，触发自动保存。
4. 刷新 B 页：氧电荷恢复为 0，标题也变为 A 页标题，没有冲突提示。

影响范围是当前示例工作台的浏览器本地草稿，不是已导出的磁盘文件。源码中示例使用固定 `storageKey`（`src/demo/main.ts:63`），编辑器直接写入同一 localStorage 项（`src/editor/chemical-editor.ts:556`）；未见跨页冲突检测。

建议按文档隔离草稿、记录版本/写入者，并在外部标签页保存后提示冲突或保留恢复版本。验收应确认 A、B 各自的化学修改都能找回，而非仅显示“已保存”。

证据：[B 页保存 −1 后](evidence/draft-before.png) → [刷新后的电荷 0](evidence/draft-after.png)。

## 已完成的关键正确性核验

- 从空白绘制乙醇为 3 个原子、2 条键；普通乙醇实际 RDKit 输出 `CCO`、`C2H6O`、平均分子量 `46.069`。结果含引擎、版本和范围。
- AI 对选中氧执行 18O 标记，其他原子、键和坐标保持，应用后一步 Undo 恢复；拒绝预览、只读模式、过期预览与停止均未把不允许的化学修改写入模型。
- 四面体/双键反转、缩写内部和递归片段、第二备选片段、多页修改等指定样例通过完整模型比对确认 Undo 恢复；四面体另验 Redo。B06 前置问题定位后，独立数值事务的 Undo/Redo 通过。
- 非法同位素、错误聚合物次数、不安全的片段提升、聚合物普通分子计算、不完整选区计算、坏 CDX 导入均保留当前文档并给出拒绝说明。安全拒绝不计为执行故障。
- 指定 CDX/CDXML、MOL、RXN、JSON 文件经实际下载并 UI 重导入核对；另验证了原始 CDX 字节保持与修改后的源格式保存。没有把这些样例推广为所有 CDX/CDXML 无损支持。

## 建议修复顺序与验收

1. **草稿可靠性**：多标签冲突处理、按文档隔离和恢复版本；验收包括两个页面交错保存与刷新。
2. **编辑与保存确定性**：焦点/原生 Undo、Ctrl+S、导入替换提示、硬限制与有损确认的区分；用真实点击后键入验证输入落在正确字段。
3. **反应化学可读性**：角色分区、反应概览和可识别候选；再补创建箭头、条件文字与自然几何编辑。
4. **AI/RDKit 阅读与追溯**：扩大结果区，停止状态统一，明确保存范围并支持结果导出；验收中英文桌面和窄屏的完整计算卡阅读。
5. **录入效率**：SMILES 快捷入口、稠环、内部片段路径、搜索别名和文本框样式。
