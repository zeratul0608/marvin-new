# Molecule Workbench 产品特色

> 面向普通二维分子的网页化学结构编辑与文件交换工作台，提供结构绘制、属性编辑、模板搜索、基础诊断、格式转换、矢量输出、编辑恢复和组件集成能力，并可按需启用 AI 助手。
>
> 本文依据当前 `0.1.0` 版本源码整理，更新日期为 2026 年 11 月 6 日。功能描述以已实现能力为准，源码对照见文末。

## 一、产品定位

Molecule Workbench 的核心是一套自研二维化学结构编辑器。它既可作为独立网页工作台使用，也可通过 SDK 嵌入其他网页应用，将分子绘制、结构属性修改、文件交换和扩展工具放到同一操作环境中。

编辑器自身承担绘图、结构数据管理、文件转换、基础检查和撤销恢复。AI 是可选插件；不配置模型服务也能使用这些基础能力。

适用场景包括普通二维分子的日常绘制与修改、已有结构文件的基础交换、教学演示，以及业务系统中的结构录入和展示。

## 三、主要产品能力

### 1. 二维结构绘制与成键交互

编辑器提供选择、单键、双键、三键、实楔键、虚楔键、六元环、苯环、删除和平移工具。

绘制时可以点击或拖动创建原子和键，也可以连接已有原子、修改已有键的键级。成键端点会吸附附近原子，默认按 30° 方向吸附；按住 Alt 可以使用自由角度。拖动过程提供临时绘制预览，便于确认落点。

六元环和苯环可直接放入画布，也可以从已有原子连接新环。苯环工具使用交替单、双键构建模板；当前没有完整芳香性感知或通用融合环绘制算法。

### 2. 原子属性与化学键描绘

原子属性面板支持以下内容：

- 从 118 种元素中选择或替换元素。
- 查看与修改形式电荷。
- 设置或清除同位素质量数。
- 选择自动推导氢数，或明确指定非图氢数。
- 设置或清除原子映射编号。
- 设置自由基自旋态，区分模板外部连接点。
- 查看、修改和清除四面体几何／双键连接顺序，同步反转支持的构型。

键属性面板支持单键、双键、三键和芳香键。对单键可以选择普通、实楔、虚楔、波浪、虚线、粗线或等宽哈线描绘，并交换锚点；普通双键可调整第二条线的偏侧。

氢数模型明确区分“自动推导”“明确指定的非图氢”和作为独立原子存在于图中的 H。原子映射编号也与内部对象 ID 分开，便于保留不同字段各自的含义。

118 种元素均可录入，日常绘图的自动氢数和价态推导采用基础规则。“化学计算”可对普通确定分子使用 RDKit 复核氢数并计算性质及常见立体标签；二维楔线及波浪描绘仍不等同于全部立体类别的完整计算。

### 3. 选区、批量编辑与片段变换

画布支持原子和键选择、框选、全选、多原子移动，以及删除选中结构。删除原子时会一并清理相连的键，避免留下无效引用。

选择多个原子后，可统一修改元素和形式电荷。选区浮动工具栏与“结构”功能栏提供左转 30°、右转 30°、水平镜像、垂直镜像和删除操作。旋转与镜像围绕操作对象的坐标中心进行；未选择原子时，结构变换可作用于整份结构。

这些操作接入同一套编辑历史，批量属性修改和一次片段变换都可以作为一步撤销。完整片段镜像同步翻转内部楔键深度；已记录的可见构型受到普通编辑保护。结构排版插件支持完整片段横排、竖排、环排和键长归一化；本地化学计算另提供普通完整分子的自动二维清理，适用于链、融合环、桥环和螺环，清理前后核对化学身份。

本地化学计算面板提供平均分子量、单同位素精确质量、计算 LogP/tPSA、环统计、常见 R/S、r/s、E/Z 指派，以及 SMILES 载入与可复制输出。首次使用才加载应用附带的 RDKit WASM，不发送结构到外部服务。查询、内部片段、轴／增强立体等仍使用原有模型编辑保存，当前计算入口会拒绝不可靠的简化。见 [详细范围](chemistry-engine.md)。

### 4. 模板预览与统一搜索

内置分子模板包括阿司匹林、咖啡因、乙醇和苯。模板库提供结构图片预览、中文名称、英文名称、分类和基础分子式，打开模板后可继续编辑，也可撤销返回先前文档。

通过 Ctrl / Command + K 打开统一搜索，可以查找并执行：

- 绘图工具。
- 全部 118 种元素。
- 内置分子模板。
- 旋转、镜像、适应画布、网格和属性面板等工作台操作。
- 已启用插件注册的命令。

搜索支持方向键选择与 Enter 执行。选择元素后，可以将其应用到当前选中原子，也可以用于下一次绘制。

### 5. 分子概览、基础诊断与结构审阅

属性面板持续显示基础分子式、原子数、化学键数和不连通片段数。数据模型允许同一文档包含多个彼此不相连的结构片段。

内置“结构审阅”插件进一步提供总形式电荷、同位素标记原子数、选中原子/键数量、文档版本与诊断数量，并在文档或选区变化时更新摘要。

电荷和同位素摘要递归统计已定义缩写的实际内部原子，排除已绑定的虚拟连接点；查询、备选和重复单元等不能唯一求值时标注统计不完整。收起片段不会让内部电荷或同位素从摘要中消失。连通选区可在属性面板中收起为自定义缩写，仍能打开内部编辑器或重新展开；单键边界、立体及引用保护范围见 [收起说明](abbreviation-collapse.md)。

该插件还提供“选中原子电荷归零”操作，将选中原子的形式电荷批量设为 0，支持一步撤销。它只修改电荷字段，不推断质子化状态，也不增删氢。

核心校验会拒绝损坏的原子或键引用、重复键、自连接、无效坐标、无效属性值及未知模型字段。无法由基础规则确定的氢数或价态会提示待校验，编辑过程中允许暂时化学不完整的结构。基础分子式与诊断不构成完整化学正确性认证。

### 6. 多格式导入导出与源码操作

| 格式 | 当前支持的主要内容 | 主要限制 |
| --- | --- | --- |
| Molecule JSON | 首版模型、稳定对象 ID、坐标、键描绘及源文件记录 | 使用固定的首版模型，未知语义字段会被拒绝 |
| CDX | 普通化学图、查询、立体排序、来源 CIP 标签、已有反应和图元的源保存 | 二进制重建和全部跨格式对象映射仍有限制 |
| CDXML | 查询、嵌套片段、反应角色、增强／轴立体排序、多中心与生物序列连接、独立三维坐标、文字与图元模型 | 部分专用图元只显示轮廓；复杂原子映射及通用聚合物适配仍有限制；本地计算限普通确定分子 |
| MRV | 普通分子、基础原子属性、原子映射、二维描绘和基础压缩原子数组 | 复杂语义、附加压缩列、S-group/R-group 与反应等暂不支持 |
| MOL V2000 | 基础结构、电荷、同位素、原子映射和二维键描绘 | 单结构，最多 999 个原子和 999 条键；查询、三维等暂不支持 |
| MOL V3000 | ATOM/BOND、基础原子属性、原子映射和基础 CFG 描绘 | COLLECTION、SGROUP、查询、三维等暂不支持 |
| RXN V2000/V3000 | 单步反应的普通二维分子、反应物／产物／试剂、原子映射及支持的反应键条件 | 多步、查询、聚合物、高级反应约束及完整图形排版暂不支持；见 [详细边界](rxn.md) |
| SVG | 独立矢量结构图片 | 用于图片输出，不承担化学结构文档往返 |

支持文件选择、拖放导入和源码粘贴，也支持格式自动识别、导出源码预览、复制源码和文件下载。失败导入不会替换当前有效文档；界面提供错误或兼容提示。

文本结构文件上限为 20 MB、原生 JSON 80 MB、CDX 2 MB；每层化学图最多 2000 个原子和 2000 条键，具体格式仍受其自身限制。CDX 支持文件选择、拖放及二进制 SDK 导入，原始字节以无损 Base64 记录随 JSON 保存。详见 [CDX 导入说明](cdx.md)。

### 7. 源文件保留与转换损失防护

导入时会记录源文件原文、可编辑模型的指纹和转换诊断。对于尚未解释的内容，系统根据其类型报告问题或拒绝导入，不会把未知伪原子直接当作碳处理。

结构、标题和布局均未改变，且导出格式与源格式相同时，可以原样返回源文件。发生编辑或跨格式转换后，若存在已知信息损失，系统默认阻止导出，并在兼容报告中说明原因。

手动导出界面可以明确勾选“允许有损导出”，SDK 也提供对应选项；AI 导出工具保持损失拦截。原生 JSON 可同时保存当前模型与源文件记录。

这套机制的价值在于让转换边界可见。原样保留文件内容不代表其中未解释的高级特征已经能够编辑，当前也尚未完成与真实 ChemDraw、Marvin JS 软件的往返兼容认证。

### 8. SVG 渲染、视图工具与工作台布局

结构使用 SVG 绘制，支持骨架式中相连普通碳标签的省略、部分常见元素配色、氢标签、同位素质量数、形式电荷和原子映射编号显示。不同键级与二维描绘拥有对应的渲染方式，选中对象会高亮显示。

视图支持滚轮缩放、按钮缩放、画布平移、适应结构范围和可选网格。SVG 导出包含独立图片所需的结构图形及样式，可用于文档、课件或演示。

工作台保留“绘制／结构／视图”基础功能栏；一键展开“高级编辑”后，按高级属性、查询条件、片段与缩写、文档与反应、扩展插件分类编辑。基础与高级共用右侧属性面板，可随时返回基本属性或收起高级栏；收起不改变化学信息、插件输入或撤销历史。窄屏时属性和插件面板以浮层方式显示。键盘快捷键覆盖工具切换、元素替换、电荷调整、全选、删除、撤销重做和导出等操作，界面内提供快捷键说明。高级功能可通过 Ctrl／⌘ K 搜索直达，同选区切换保留未提交草稿、折叠状态与各分类滚动位置。底部支持中文／English 切换，演示页记住语言偏好，用户化学标签、对话、源码和输入值保留原文。

### 9. 编辑历史、事务回滚与本地草稿

文档存储提供最多 100 步撤销历史，并支持重做。操作先在文档副本上执行，通过校验后才提交；校验失败不会污染当前文档。历史快照保留稳定原子和键 ID，撤销后可以恢复相同对象身份。

本地草稿可按实例配置存储键。演示工作台默认开启浏览器草稿，文档变更后保存当前结构，刷新页面时尝试恢复；SDK 默认关闭，宿主应用可按需启用。

草稿恢复针对当前文档，不表示撤销历史、界面状态或 AI 对话会跨刷新保存。浏览器存储不可用时会提供状态提示，基础会话编辑仍可继续。

### 10. 独立模型、SDK 与插件扩展

项目将分子图、二维坐标和键描绘分开保存，以稳定 ID 管理原子和键。移动、旋转等布局操作可以保持结构对象身份，格式转换也有独立的适配器层。

对业务系统的集成能力包括：

- 通过 Web Components 和 Shadow DOM 封装编辑器，可接入普通网页、React 或 Vue。
- 多实例的文档、历史、事件和样式独立，支持注册业务自定义标签。
- 公开文档快照、选区、诊断、导入导出及撤销重做等接口。
- 批量编辑支持临时对象引用和版本检查，一批操作作为一个事务提交。
- 通过文档、选区变更事件触发宿主系统的保存或其他业务操作。
- 通过统一 JSON 命令入口调用公开能力。
- 核心模型和格式适配器可独立调用；XML 适配器依赖兼容的 DOM 实现。

插件支持实例级安装、启用、停用和卸载，可以添加命令、属性面板及事件订阅。插件命令也可进入统一搜索，停用或销毁时会释放通过上下文注册的资源。插件为可信同页面代码，当前机制不提供不可信代码沙箱。

### 11. 可选 AI 助手与模型设置

AI 助手通过公开编辑工具读取当前结构、选区、版本和诊断，并执行用户要求的编辑、模板加载、结构源码导入、检查、导出及撤销重做。面板提供实时上下文预览、工具执行记录、停止操作和导出下载链接。

模型设置支持自填服务地址、模型 ID 和可选密钥，提供 Responses 与兼容 Chat Completions 两类协议，可连接本地模型或兼容网关。连接测试验证基础工具调用，部分兼容服务可显式设置思考模式。本机已用 Docker 中的 Qwen 3.6 27B 完成真实编辑联调。

AI 修改使用版本检查和批量事务；只读模式由程序限制修改工具。模型连接由所配置的服务地址决定，API 密钥只保存在本地网关进程的会话内存中。系统不会自动向模型发送原始导入文件，但主动粘贴进对话的源码会作为对话内容发送。

## 四、典型使用流程

### 已有结构文件的修改与交换

1. 拖入 CDX、CDXML、MRV、MOL 或原生 JSON 文件。
2. 查看分子概览和兼容报告，确认当前支持范围。
3. 选择原子、键或片段，修改属性与布局。
4. 核对结果，必要时撤销或重做。
5. 预览导出源码并下载目标格式文件；存在已知损失时先查看报告。

### 从模板开始绘制与展示

1. 打开模板库预览分子，或使用环工具开始绘制。
2. 通过成键、元素替换和属性面板调整结构。
3. 使用旋转、镜像、平移、缩放和适应画布调整视图。
4. 查看基础分子式、片段、电荷和诊断信息。
5. 保存结构文件，或导出 SVG 作为插图。

### 嵌入业务系统

1. 在业务页面创建编辑器实例并加载文档。
2. 通过公开 API、事件和批量事务连接业务流程。
3. 按需注册审阅、处理命令或自定义面板。
4. 由业务系统实现自己的保存、提交、审核及权限管理。
5. 如需自然语言操作，再启用和配置 AI 助手插件。

## 六、当前验证与能力边界

截至 2026 年 10 月 27 日，最近一次本地运行中，156 项自动化测试、类型检查及工作台和 SDK 构建通过。测试涉及模型与氢策略、数据完整性、几何变换、编辑事务、格式转换与损失防护、多实例、草稿、公开 API、插件生命周期和 AI 调用等能力。

真实 Qwen 联调验证了选区上下文、氧-18 属性修改、结构检查、MRV 导出、自然语言撤销重做及只读模式。上述结果对应已测试场景，不构成所有化学结构、模型服务或目标软件的兼容保证。

当前尚未接入 SMARTS、SDF 多记录、通用 Markush／聚合物求值、全部立体类别的 CIP、三维建模和名称转结构引擎。已有单条分子 SMILES、普通分子清理及常见立体标签计算。反应、查询、嵌套片段和立体顺序的解析编辑不等于覆盖全部 ChemDraw 功能。本机样本排除 2 份故意无效输入后，685/685 份通过导入及适用编辑保存回读；源文件有 3 处未附内部图的命名标签仍明确标为未定义，部分专用图元仍为轮廓显示。见 [完整范围与验证](engine-upgrade.md)。

本地草稿并非云端存储，基础诊断并非完整化学认证，SDK 的版本检查也不等同于多人实时协作。账号、权限、多人托管、公司资料检索和实验系统连接需要由后续产品模块或宿主业务系统实现。

## 七、可复用的产品简介

Molecule Workbench 是一款自研网页二维化学结构编辑与文件交换工作台。它提供分子绘制、原子与键属性编辑、片段变换、模板搜索、结构摘要、多格式交换和 SVG 输出，并通过撤销历史、本地草稿及转换诊断支持日常修改与保存。产品同时提供可嵌入 SDK 和插件机制，便于接入其他网页系统；按需启用 AI 助手后，还可通过自然语言调用已有编辑能力。
