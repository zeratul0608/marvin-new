# ChemDraw 解析与编辑引擎升级

编辑与格式适配位于现有 TypeScript 引擎，没有加载 ChemDraw DLL，也没有复制其反编译实现。格式字段依据公开 CDX/CDXML 规范及本地静态属性表核对，独立实现数据模型、编辑校验和保存。普通分子的计算与自动排版另接入开源 RDKit WASM，在本机浏览器运行。

## 新增的编辑能力

- **查询结构**：元素列表及 NOT、通用基团名称、任意原子、任意查询键及 2.5 键。不会把查询对象当作普通碳或给出虚假的完整分子式。
- **高级查询字段**：具体元素保持不变，可独立设置取代数、环键数、不饱和及反应变化／立体查询；支持键的环／链拓扑和显式 RingOrChain。CDX/CDXML 导入、重建、来源增改清除及跨格式写出均保留字段。查询声明不执行立体翻转，不进入普通确定分子的 RDKit 计算。见 [语义说明](query-constraints.md)。
- **内部化学片段**：缩写、昵称、备选组的内部原子和键独立递归解析；外部键与内部连接点显式映射。属性面板可打开内部编辑器，保存作为一步历史操作，支持撤销重做。
- **原子级展开**：单层／递归展开已定义且内外同阶的单／双／三键端口缩写，保持边界映射和内外构型；同步反应参与者、分组与聚合物成员，并提升原生内部节点进行 CDXML 来源保存。整体注释及歧义仍受保护，见 [详细说明](abbreviation-expansion.md)。
- **复杂群组展开与编辑**：保留残基、整体注释、备选及引用身份，将实际内部图和全部候选显示为可编辑结构卡片。完整层级路径定位内部原子／键，修改保存接入主历史；JSON/CDXML 保存展开状态。参见 [功能说明](expanded-groups.md)。
- **选区收起**：将连通选区收起为保留真实内部图的可编辑缩写，建立单键边界端口，核对内外立体关系；支持内部继续修改、重新展开、JSON 恢复和撤销重做。CDXML 来源保存搬移原生节点并保留字体、线宽等样式，支持展开后改名收起的历史；跨范围或歧义引用仍拒绝。见 [收起说明](abbreviation-collapse.md)。
- **RXN 反应交换**：单步 V2000/V3000 导入和重建导出，保留反应物／产物／试剂、普通二维分子、映射及受支持的 RXCTR。多步、查询、聚合物及高级约束仍受明确保护；不承担完整文档图元保真。见 [RXN 说明](rxn.md)。
- **立体化学数据**：四面体与轴手性配体排序、双键环周顺序、增强立体 And/Or/Absolute 分组。检查引用与轴路径。普通坐标编辑保护已有可见构型；四面体与无环双键提供适用范围内的反转操作。
- **来源与计算 CIP 标签**：AS/BS 进入模型作为来源缓存；化学修改后清除未重新指定的缓存及相关派生文字。另可在“化学计算”中根据当前普通分子的二维图与楔键重新计算常见 R/S、r/s、E/Z，写入属性并显示在画布和 SVG 中；不从旧缓存推断构型，也不自动指定未定义中心。
- **复杂化学连接**：多中心连接、外部连接点、PolymerBead 多连接载体、残基编号、生物序列连接方式、外部端口编号、反应键变化条件。
- **聚合物括号组**：依据本地原生属性分派记录和公开规范，独立补齐 SRU／MultipleGroup／共聚物等类型、FLOAT64 重复次数、连接和翻转模式、成员及嵌套组、跨括号键与组内端点。支持可见属性修改、边界改绑、删除清理及来源保存；方／圆／花括号和次数／标签可见。见 [功能范围](polymers.md)。
- **文档与反应**：反应方案、步骤、反应物、产物、箭头、条件、加号、原子映射关系；独立文字、图元、曲线、图片、分组、页面及对象引用进入模型。可选择、移动、修改属性、删除适用图元及调整反应角色。
- **页面与坐标**：多页可单独选择显示和编辑；保留独立三维坐标，不因二维移动而覆盖。交叉键可引用另一片段的键，并保留层次、标签连接偏移与第二条键线描绘。
- **保存**：保留文字所在的来源片段及对象层级；CDXML 支持文档模型重建；CDX 支持已有反应及图元的来源保存。没有完整映射的跨格式写入会明确拒绝。
- **大小限额**：CDXML/MRV/MOL 文本 20 MB，原生 JSON 80 MB，CDX 二进制 2 MB；每层化学模型仍最多 2000 个原子和 2000 条键。
- **本地化学计算**：RDKit 2026.09.1 提供普通分子的二维清理、芳香性感知、分子式、平均分子量、精确质量、LogP/tPSA、环统计及 SMILES 输入／输出。通过稳定原子身份映射更新坐标，清理前后核对异构 SMILES；保留其他图元及反应数据。见 [接入说明和明确边界](chemistry-engine.md)。

## 明确边界

文件集通过表明这些输入及上述适用编辑路径通过回归，不能证明所有可能的 ChemDraw 文件或任意编辑组合均受支持。跨来源片段合并、未知私有属性、某些混合字体化学标签、共享立体键自动反转及复杂端口重接仍可能被保护检查阻止；失败保留原文档和历史。

源文件有 **3 处未附内部原子图的命名标签**，其中包含 ChemDraw 自己的无法解释／价态警告。编辑器保留名称和外部连接，明确显示内部结构未定义，并允许用户补全；不会凭名称制造内部化学图。

专用 BioDraw、凝胶、质粒、表格等对象的参数和引用保留可编辑，但部分仍用轮廓表示，尚不具备 ChemDraw 的完整专用绘制器。图像仅作为图像编辑，不会冒充图像内的分子已经解析。没有通用聚合物／Markush 求值、螺旋立体感知或名称转结构引擎。自动清理和计算入口目前拒绝查询、内部缩写片段、轴／增强立体、多中心连接等，保留其原编辑模型；不把这些内容简化为普通原子。

尚未在商业 ChemDraw/Marvin JS 中完成全面往返认证。CDX 定点数保存遵循格式精度；文档保留不表示任意浮点坐标可无限精确写入。

## 复现

先运行 npm test 和 npm run build，再执行：

```powershell
node --expose-gc scripts/audit-chemdraw-corpus.mjs .local/chemdraw26-unpacked/files docs/validation/chemdraw26/corpus-results.json
node scripts/validate-document-browser.mjs
```

浏览器脚本要求项目已在 5173 端口运行，并可传入 Playwright 模块路径。安装包、反编译产物及商业样本仅留在本地忽略目录，不随测试样例发布。

规范：[CDX 属性表](https://iupac.github.io/IUPAC-FAIRSpec/cdx_sdk/TableOfProperties.htm)、[ChemDraw CDXML DTD](https://static.chemistry.revvitycloud.com/cdxml/CDXML.dtd)。
