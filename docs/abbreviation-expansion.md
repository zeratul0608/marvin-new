# 缩写的原子级展开

在已有递归片段模型及内部编辑器上，新增将已定义缩写提升到主画布的编辑操作。依据明确的内部图和端口连接实现；没有从名称猜测分子，也没有调用 ChemDraw DLL。

## 已实现

- **展开一层**：用真实内部原子、键替换缩写节点；绑定的虚拟端口移除，外部键接到相应内部锚点。未绑定的模板端口保留，不自动补成氢。
- **递归展开**：继续展开当前片段内的已定义缩写。遇到歧义或保护条件时，整次操作失败，不提交部分展开结果。
- **身份与构型**：保留已有外部原子和键 ID；提升的内部原子和键优先保留原 ID，只有与当前主图冲突时才使用确定性的 `expandedId` 哈希。绑定端口移除，端口键合并到已有外部键 ID。这使新建收起片段再次展开时能够恢复原有身份，也支持 JSON 恢复。仅用旋转和平移定位内部图，不镜像；四面体和双键构型在内外图之间复核，边界楔线冲突时拒绝。派生 CIP 缓存失效后可重新计算。
- **增强立体组**：内部 And／Or 组号未与主图同类型组冲突时保留；冲突时分配空闲组号，先预留其他内部组原有的可用号码。
- **文档引用**：同步页面／分组成员、反应分子参与者及聚合物成员；聚合物边界的组内端点依据对应外部键重新定位。单个原子映射不能猜测为多个内部原子。
- **保存**：CDXML 来源保存将已有内部原生节点移到父片段，重编号并维护引用，保留内部原子原有的已支持属性和标签样式。随后继续编辑及 JSON 恢复后的源保存可用。可重建 CDXML；普通展开图另可新建导出 CDX。

操作入口：选择一个缩写节点，在右侧“结构”点击“转为主图原子（单层）”或“转为主图原子（递归）”。一次操作对应一步撤销。展开后可全选普通完整分子，使用本地化学计算和二维清理。需要保留整体注释或全部候选时，使用[群组展开视图](expanded-groups.md)的“展开结构并编辑”。

```ts
const snapshot=editor.getSnapshot();
editor.applyEdits({expectedRevision:snapshot.revision,operations:[{
  type:'expand-substructure',atomId:snapshot.selection.atomIds[0],recursive:true,
}]});
```

## 保护范围

当前支持具有唯一内部结构、内外同阶单／双／三键端口的缩写。边界双键的显式环周排序需要进一步的双侧合并，仍受保护；不能仅保留一侧而丢弃另一侧。未定义名称、未选定的备选组、整体电荷／同位素／原子映射、生物残基与连接语义、内部独立图元或反应、冲突描绘及一对多原子引用不会被静默简化。这些已定义内部图可在群组展开视图中呈现并编辑，保留原包装节点和引用身份。

内部端口先改绑、再展开的组合，目前可能无法完整恢复全部来源属性，源保存会明确拒绝；即使随后将展开图再次收起，也不会绕过这一保护。JSON 保留完整模型，必要时可使用已报告损失的重建导出。未映射的私有引用仍受保存保护。缩写标签和包装节点会被真实结构取代，展开后的排版不承诺与原标签像素一致。

支持将符合边界条件的完整连通选区[重新收起为可编辑缩写](abbreviation-collapse.md)。CDXML 来源保存依据整个目标层级识别对象：原缩写包装节点仍在某个内部片段时只搬移；原包装节点已消失、其提升原子进入新缩写时，先保留原生展开来源，再搬入新缩写。相关局部 ID 在多个目标层级重复、去向不唯一时明确拒绝保存。

## 验证

[专项测试](../tests/expansion.test.ts)覆盖单端口、双端口、递归、内外手性和 E/Z、边界楔线、反应与聚合物引用、后续编辑、来源属性、JSON、撤销及可见按钮。

[多重键专项](../tests/expansion-multiple-bond.test.ts)另覆盖同阶双／三键、键型不一致、边界显式排序、内外注释冲突、邻近立体对应及真实 NR 来源保存。

[原生验证](validation/expansion/independent-results.json)由 Python RDKit 2025.03.6 独立读取原始嵌套 CDXML，比较展开后 CDX/CDXML 的异构 SMILES、原子／键数量和手性。4 份原始结构对应 8 份展开输出均一致；这是独立运行时和解析器验证，仍属于 RDKit 工具包，不能代替 ChemDraw 认证。

[浏览器报告](validation/expansion/browser-results.json)记录 4 份文件的真实按钮、可见原子、计算、撤销重做和下载回读。手动样例位于 `/test-files/index.html` 的 `11-abbreviation-expansion`。
